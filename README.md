# Shadows Byte Gaming Official

Reimplementación estática creada desde cero para la comunidad Shadows Byte Gaming Official.

## Incluye

- Portada responsive de estética gaming, anime y neón.
- Páginas de comunidad, anime/manga, gaming, noticias, miembros, contacto y acceso.
- Navegación sin dependencias con rutas basadas en hash.

## Uso

Abre `index.html` en un navegador o publica este repositorio con GitHub Pages.
